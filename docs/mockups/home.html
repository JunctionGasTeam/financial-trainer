Layout decisions

  • Hero first, always. The safe figure is the only Display-size number on the screen.
  • Balance curve is projected from today, so the whole line is dashed and only today's point is solid.
  • Basket bars share one scale (Aino's largest bar, EUR 1 363.01). The thin bar under each is the usual month on the same scale.
  • The ask field on Home opens Chat with the keyboard up. It is not a second chat.

States covered

  • Normal (Aino), well covered (Mikko), insights with a question (Sara).
  • Shortfall: the warning hero from step 0 replaces the green one. Text and icon use the warning ink only.
  • Loading: each card shows a skeleton of its own shape, as under Sara's baskets.
