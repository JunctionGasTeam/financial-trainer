Glass materials

Three textures from the reference board, one per role. Each pane below sits over the same mesh with dark stripes behind it, so you can see how much each one blurs. Fill opacities are the lowest that keep textMuted at AA over the darkest blob (see contrast below).

Frosted · cards, lists, nav

Clear frosted

Cards, lists, insights, inputs, chips, the nav capsule. Blur 20 px, saturate 160%, white fill 0.82 under text (0.55 with no text).

background: rgba(255,255,255,.82);
backdrop-filter: blur(20px) saturate(160%);
border: 1px solid rgba(255,255,255,.7);
box-shadow:
  inset 0 1px 0 rgba(255,255,255,.9),
  inset 0 -1px 0 rgba(11,94,75,.08),
  0 8px 24px rgba(11,94,75,.12);
::before  linear-gradient(135deg,
  rgba(255,255,255,.35), transparent 45%)
Reeded · hero, sheets

Reeded

HeroFigure and bottom sheets. Frosted base with a tint (0.94) or white (0.88 for sheets, which sit over the scrim), plus fluted ribs every 8 px.

background: rgba(215,251,232,.94);
backdrop-filter: blur(20px) saturate(160%);
/* + frosted edge and sheen */
::after repeating-linear-gradient(90deg,
  rgba(255,255,255,.18) 0 2px,
  transparent 2px 7px,
  rgba(11,94,75,.04) 7px 8px)
Rippled · the backdrop

Rippled backdrop

The screen itself: radial blobs of the four brand greens over bg, under a hammered ripple made from SVG noise. The ripple only adds white highlights, so it never darkens what glass sits on.

background:
  url(ripple.svg) center / cover,
  radial-gradient(… #1FAB89 …),
  radial-gradient(… #62D2A2 …),
  radial-gradient(… #9DF3C4 …),
  radial-gradient(… #D7FBE8 …), #F7FAF9;
ripple.svg = feTurbulence fractalNoise
  (.014 .03, 3 octaves) → feDiffuseLighting
  → feColorMatrix (highlights only)
